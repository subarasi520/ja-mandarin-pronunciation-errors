# Changelog

## 2.1.1 (2026-11-25)

The knowledge itself is unchanged (dictionary version 2.1). Added for easier use: Excel workbooks with Chinese
headers and filters (`data/excel/`); tone-marked pinyin and common example characters for every toned syllable;
the main README is now in Chinese and written for teachers, with uses for teaching, research and commercial
development.

知识内容不变（字典版本 2.1）。为了方便使用，新增：中文表头、带筛选的 Excel 表（`data/excel/`）；每个带调音节的带调号拼音和常用例字；
README 主页改为中文，面向老师重写，分教学、研究、商业开发介绍用法。

## 2.1.0 (2026-11-25)

First public release: Error Coding Dictionary with 31 entries (grades A 16, B 6, C 6, D 3) and Error
Mapping Table for 410 toneless and 1,295 toned syllables with a neutral-tone layer; JSON and CSV;
Python package and command line tool.

首次公开：《错误编码字典》31 条（A 16、B 6、C 6、D 3），《错误映射表》410 个基础音节、1295 个带调音节及轻声层；JSON 与 CSV；Python 包和命令行工具。
