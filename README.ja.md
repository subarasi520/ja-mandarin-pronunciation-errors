# 日本語母語話者の中国語（普通話）発音の体系的な誤り：知識ベース

[English](README.md) · [中文](README.zh-CN.md) · バージョン 2.1.0 · **非商用ライセンス：研究と非営利の教育に限り利用可**（[LICENSE](LICENSE)）

日本語母語話者が中国語（普通話）を発音するときの体系的な誤りについて、既発表の研究の知見を証拠レベル付きで整理した知識ベースです。

- **誤り符号化辞書（ECD）**：声母・韻母・声調・リズム（連続発話）の4側面、31類。各項目に固定コード（例：`INIT-001`）、
  目標音と誤りの現れ方（ピンインとIPA）、要因、生じる環境、産出か知覚か、**証拠レベル A〜D**、証拠の要約と文献を記載しています。
- **誤りマッピング表（EMT）**：辞書を普通話のすべての音節に対応づけた表です。声調なし 410 音節、声調付き 1,295 音節、軽声は別表。
- 23 件の研究にもとづき、すべて原典で確認しています。31類のうち 16類は 2 件以上の独立した実証研究で一致して支持され（A）、
  9類は教育現場の観察や推論にとどまります（C・D）。後者は検証前の仮説として扱ってください。

## すぐに使う

- **データだけ**：[`data/ecd.csv`](data/ecd.csv) と [`data/emt_toned.csv`](data/emt_toned.csv) を Excel などで開けます。同じ内容の JSON もあります。
- **Python**（3.9 以上）：

```bash
pip install "ja-mandarin-errors[text] @ git+https://github.com/subarasi520/ja-mandarin-pronunciation-errors"
ja-mandarin-errors jiā 书 INIT-001
```

```python
from ja_mandarin_errors import KnowledgeBase
kb = KnowledgeBase()
kb.syllable("nǚ")        # "nv3" でも可。声調なしは声調なしの表、5声は軽声
kb.entry("TONE-001")
kb.text("你好")          # 漢字から引く（pypinyin が必要）
```

項目名は中・英・日の3言語、説明と音節ごとの短い注記は中・英の2言語です。証拠の要約・要因・環境は中国語のみで、両言語が食い違う場合は中国語が優先します。

## 使い方の例

- 実験刺激の選定（例：`INIT-001` と `INIT-008` が重なる zh/ch/sh と j/q/x の音節、知覚実験の最小対）
- C・D の 9 項目を学習者コーパスで一つずつ検証し、表にない出現頻度を補う
- ECD のコードを誤りカテゴリとして使い、研究間で結果を比較できるようにする
- 教材の語彙がどの証拠レベルの誤りに関わるかを数え、教材を比較する研究
- 他の母語の学習者に同じ項目設計と評価規則を当てはめる比較研究
- 非営利の授業で、新出語の音節にどの誤りが起こりうるかを確認する（C・D は観察の対象として）

## 使う前に

- マッピング表が示すのは、その音節で**起こりうる**誤りであり、頻度ではありません。
- 新しい音声データは収集していません。多くの研究は参加者 30 人未満で、文献収集は系統的レビューの手順によるものではありません。
- 音節は本来の声調で引きます（変調は適用しません）。`kb.text()` は pypinyin の読みに依存し、多音字を誤ることがあります。
